# শিখি — অনলাইন কোর্স ওয়েবসাইট

বাংলা ভাষার, মোবাইল-ফ্রেন্ডলি একটি স্ট্যাটিক কোর্স ওয়েবসাইট। HTML, CSS ও Vanilla JavaScript দিয়ে তৈরি; কোনো বিল্ড স্টেপ বা পেইড টুল লাগে না।

## বর্তমান সেটআপ

1. `script.js`-এর `CONFIG`-এ বিকাশ/নগদ নম্বর এবং Google Form URL সেট করা আছে। পরিবর্তন করলে নতুন তথ্য শুধু নিজের অনুমতিতে প্রকাশ করুন—পেমেন্ট নম্বর সাইটে প্রকাশ্যে দেখা যায়।
2. এনরোলমেন্ট Google Form-এ শিক্ষার্থীর নাম, মোবাইল, কোর্স, ট্রানজ্যাকশন আইডি, পেমেন্ট মাধ্যম ও স্ক্রিনশট চাওয়া হয়। বাংলাদেশের মোবাইল নম্বর বাংলা বা ইংরেজি অঙ্কে লেখা যায়; যাচাইয়ের আগে বাংলা অঙ্ক ইংরেজি অঙ্কে রূপান্তরিত হয়। ফাইল আপলোডের কারণে শিক্ষার্থীকে Google-এ সাইন-ইন করতে হবে; আপলোডের সময় Google Account-এর নাম, ইমেইল ও ছবি রেকর্ড হতে পারে। আলাদা ইমেইল সংগ্রহ বন্ধ আছে।
3. `index.html`-এ ব্র্যান্ড/যোগাযোগের তথ্য বদলাতে পারেন। কোর্সের নাম, মূল্য, ক্লাস ও বিবরণ `script.js`-এর `courses` তালিকায় সম্পাদনা করা যাবে।
4. Google Form-এর উত্তর `Shikhi Enrollment (Responses)` spreadsheet-এ লিংক করা আছে। উত্তর এলে সেখানে ট্রানজ্যাকশন আইডি দেখে পেমেন্ট ম্যানুয়ালি যাচাই করে কোর্সের নির্দেশনা পাঠান।

এনরোলমেন্টে নাম, মোবাইল, কোর্স, ট্রানজ্যাকশন আইডি ও পেমেন্ট মাধ্যম Google Form-এর prefill URL-এ দিয়ে নতুন ট্যাবে খোলা হয়। এই URL ব্রাউজারের ইতিহাসে থাকতে পারে। শিক্ষার্থীকে স্ক্রিনশট যোগ করে Google Form-এ নিজে Submit করতে হবে; উত্তরগুলো Google Forms/Drive-এ সংরক্ষিত হয়। এই স্ট্যাটিক সাইট নিজে কোনো তথ্য সংরক্ষণ করে না। ফর্মে প্রশ্ন মুছলে/পুনরায় বানালে `script.js`-এর `entry.*` আইডিগুলোও মিলিয়ে আপডেট করুন। এনরোলমেন্টে বাংলাদেশি মোবাইল নম্বরের ফরম্যাট যাচাই হয় এবং কোর্স বাছলে মোট মূল্য দেখায়।

## বিশ্বাসযোগ্যতার জন্য প্রকাশের আগে

- কোর্সের মূল্য, সিলেবাস, মেয়াদ, ক্লাস/রিসোর্স কীভাবে দেওয়া হবে এবং সহায়তা/রিফান্ডের শর্তগুলো বাস্তব ব্যবস্থার সঙ্গে মিলিয়ে লিখুন।
- Google Forms/Drive-এ enrollment proof-গুলো private রাখুন; spreadsheet-এ public link sharing চালু করবেন না।
- বাস্তব শিক্ষার্থীর অনুমতি ছাড়া testimonial, review, income claim বা শিক্ষার্থীর সংখ্যা যোগ করবেন না।
- Google Form-এ স্ক্রিনশট দিতে Google-এ সাইন-ইন লাগে; অ্যাকাউন্টের নাম, ইমেইল ও ছবি রেকর্ড হতে পারে। ফর্মে এ বিষয়ে শিক্ষার্থীকে জানানো আছে।
- কোর্সে অ্যাক্সেসের মেয়াদ এবং রিফান্ডের নিয়ম এখনো সাইটে নির্দিষ্ট নেই; নীতিগুলো ঠিক করে পেমেন্ট নেওয়ার আগে প্রকাশ করুন।
- কোর্স কার্ডে Pexels-এর চারটি স্টক ছবি ব্যবহার করা হয়েছে। ছবিগুলো `assets/` ফোল্ডারে আছে, তাই সাইট প্রকাশের সময় ফোল্ডারটিও আপলোড করুন। কার্ডে দ্রুত লোডের জন্য ছবিগুলো ৮০০ পিক্সেল চওড়ায় অপটিমাইজ করা হয়েছে এবং HTML-এ আসল মাপ দেওয়া আছে। ছবির উৎস ও নির্মাতার লিংক কোর্স অংশের নিচে দেওয়া আছে। Pexels-এর লাইসেন্সে ছবি বিনামূল্যে ব্যবহার করা যায়; ক্রেডিট বাধ্যতামূলক নয়, তবে সাইটে সৌজন্যক্রমে ক্রেডিট রাখা হয়েছে।
- আগের নিজস্ব SVG ইলাস্ট্রেশনগুলো `course-*.svg` ফাইলে সংরক্ষিত আছে।
- Google Form পপ-আপ বন্ধ থাকলে এনরোলমেন্ট feedback-এর বিকল্প লিংক দেখায়। সাইট নিজে তথ্য সংরক্ষণ করে না এবং Google Form-এ স্বয়ংক্রিয়ভাবে Submit করে না।
- সামাজিক মাধ্যমে লিংক শেয়ার করলে শিরোনাম, বিবরণ ও কোর্সের ছবি দেখানোর জন্য Open Graph/Twitter metadata এবং একটি favicon যোগ করা হয়েছে।
- `index.html`-এর ডেমো ক্লাস অংশে চারটি প্রকাশ্য বাংলা YouTube ভিডিওর থাম্বনেইল আছে। দর্শক ভিডিও চালাতে চাপলেই এমবেড লোড হয়, যাতে শুরুতে পেজ হালকা থাকে। এগুলো স্বতন্ত্র নির্মাতাদের ভিডিও, শিখি প্ল্যাটফর্মের নিজস্ব কোর্স নয়; প্রতিটি ভিডিওর পাশে নির্মাতার নাম ও মূল YouTube লিংক দেওয়া আছে। ভিডিও YouTube থেকে সরানো হলে বা এমবেড বন্ধ থাকলে মূল লিংক ব্যবহার করুন।
- মোবাইলে কোর্স তুলনার টেবিলটি ছোট কার্ড হিসেবে দেখায়, তাই পাশের দিকে স্ক্রল করতে হয় না। প্রতিটি কোর্সের বিস্তারিত পপআপ থেকে সংশ্লিষ্ট ডেমো ভিডিওতে সরাসরি যাওয়া যায়। পপআপের শিরোনাম ও বিবরণ স্ক্রিন রিডারকে দেওয়া হয়। পপআপে কোর্সের লিংক শেয়ার করলে সরাসরি সেই কোর্সের বিস্তারিত খোলে। সিলেবাস প্রিন্ট বা PDF হিসেবে সেভ করা যায়। সিস্টেমে কম মোশন বেছে রাখা থাকলে সেকশনে যাওয়ার সময় অ্যানিমেটেড স্ক্রল বন্ধ থাকে। কোর্স কার্ডের ভর্তি শর্টকাট ফর্মে কোর্সটি বেছে নিয়ে পেমেন্ট অংশে নিয়ে যায়। পেমেন্ট অংশে নম্বর, কোর্স/মূল্য যাচাই, রসিদ সংরক্ষণ এবং ম্যানুয়াল যাচাইয়ের ধাপগুলো স্পষ্ট করে দেখানো হয়।

## কম্পিউটারে চালানো

1. `index.html`, `style.css`, `script.js`, `favicon.svg`, `assets/` ফোল্ডার এবং চারটি `course-*.svg` একই ফোল্ডারে রাখুন।
2. `index.html`-এ ডাবল-ক্লিক করে ব্রাউজারে খুলুন; অথবা VS Code-এ ফোল্ডারটি খুলে Live Server extension থাকলে **Go Live** চাপুন।

## GitHub Pages-এ বিনা খরচে প্রকাশ

1. [github.com](https://github.com)-এ সাইন ইন করে **New repository** দিয়ে একটি repository তৈরি করুন।
2. `index.html`, `style.css`, `script.js`, `favicon.svg`, `assets/` ফোল্ডার এবং চারটি `course-*.svg` repository-র root-এ আপলোড করে **Commit changes** চাপুন। `README.md`-ও যোগ করতে পারেন।
3. repository-এর **Settings → Pages** খুলুন। **Build and deployment** অংশে **Deploy from a branch** বাছুন।
4. Branch হিসেবে `main` ও folder হিসেবে `/(root)` নির্বাচন করে **Save** চাপুন।
5. কয়েক মিনিট পর Pages-এর উপরে দেখানো `https://আপনার-ইউজারনেম.github.io/repository-name/` ঠিকানায় সাইট খুলুন। GitHub Pages-এর ফ্রি সুবিধা public repository-তে ব্যবহার করুন।

### VS Code থেকে GitHub-এ পাঠানো (ঐচ্ছিক)

VS Code-এ ফোল্ডার খুলে Source Control থেকে **Initialize Repository** চাপুন। তিনটি সাইট ফাইল stage করে commit করুন, তারপর **Publish to GitHub** বেছে নিন। এরপর GitHub-এ গিয়ে উপরের **Settings → Pages** ধাপগুলো সম্পন্ন করুন। Git CLI ব্যবহার করলে GitHub-এর repository URL বসিয়ে `git remote add origin ...`, `git add .`, `git commit -m "Add course website"` এবং `git push -u origin main` চালান।

## Vercel-এ বিনা খরচে প্রকাশ

1. ফাইলগুলো GitHub repository-তে commit/push করুন।
2. [vercel.com](https://vercel.com)-এ GitHub দিয়ে সাইন-ইন করুন। **Add New → Project** থেকে repository-টি **Import** করুন।
3. Framework Preset **Other** রাখুন; Build Command ও Output Directory ফাঁকা রাখুন। **Deploy** চাপুন।
4. Vercel একটি `*.vercel.app` ঠিকানা দেবে। পরের GitHub push-এ স্বয়ংক্রিয়ভাবে নতুন deployment হবে।

## নোট

- সাইটটি সম্পূর্ণ static; লগইন, ভিডিও হোস্টিং, পেমেন্ট যাচাই বা স্বয়ংক্রিয় এনরোলমেন্ট backend যুক্ত নেই। কোর্স কার্ডের সারাংশ HTML-এও আছে; বিস্তারিত পপআপ, পেমেন্ট নম্বর কপি ও ফর্মের কাজের জন্য JavaScript চালু থাকতে হবে। কোর্স অংশে সময়কাল, মূল্য ও শেখার ফলাফলের তুলনা-টেবিল আছে।
- Google Fonts-এর জন্য ইন্টারনেট সংযোগ থাকলে বাংলা ফন্ট সুন্দর দেখাবে; সংযোগ না থাকলেও সিস্টেম ফন্টে সাইট চলবে।
- কোর্সের দাম, পেমেন্ট নম্বর ও নীতিমালা প্রকাশের আগে যাচাই করুন।
- পেমেন্ট নম্বর কপি বাটনে clipboard permission না থাকলে নম্বরটি বার্তায় দেখায়, যাতে শিক্ষার্থী হাতে লিখতে পারেন।
- কিবোর্ড ব্যবহারকারীরা Tab চাপলে মূল কনটেন্টে যাওয়ার লিংক পান; দৃশ্যমান focus নির্দেশকও রয়েছে।
